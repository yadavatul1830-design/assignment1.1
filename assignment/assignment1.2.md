Q1. How do you install Visual Studio Code?

Answer: Download Visual Studio Code from https://code.visualstudio.com/ and install it on your computer.

Q2. How do you install Node.js?

Answer: Download the LTS (Long-Term Support) version of Node.js from https://nodejs.org/ and install it.

Q3. Which extensions are installed in Visual Studio Code?

Answer: The following extensions are installed:

1. Live Server
2. Prettier – Code formatter

Q4. How do you create the project folder?

Answer: Create a folder named "web-development-practice" and open it in Visual Studio Code.

Q5. Which files are created inside the project folder?

Answer: Three files are created:

1. "index.html"
2. "style.css"
3. "script.js"

Q6. What is the purpose of the index.html file?

Answer: The "index.html" file defines the structure and content of a webpage using HTML.

Q7. What is the purpose of the style.css file?

Answer: The "style.css" file is used to design the webpage by adding colors, fonts, spacing, and other styles.

Q8. What is the purpose of the script.js file?

Answer: The "script.js" file adds interactivity and functionality to the webpage using JavaScript.

Q9. How do you run an HTML file using Live Server?

Answer: Open the project folder in VS Code, right-click "index.html", and select Open with Live Server. The webpage will open in the browser.

Q10. How do you verify the installation of Node.js?

Answer: Open the VS Code terminal and type:

node -v

The command displays the installed Node.js version.

Q11. How do you verify the installation of npm?

Answer: Type the following command in the terminal:

npm -v

The command displays the installed npm version.

Q12. What is Node.js?

Answer: Node.js is a JavaScript runtime that allows JavaScript code to run outside a web browser.

Q13. What is npm?

Answer: npm stands for Node Package Manager. It is used to install and manage JavaScript packages.

Q14. What is Live Server?

Answer: Live Server is a VS Code extension that runs an HTML webpage on a local development server and automatically refreshes it when supported files are saved.

Q15. What is Prettier?

Answer: Prettier is a code formatting tool that automatically formats code to make it neat and readable.

Q16. What is the difference between HTML, CSS, and JavaScript?

Answer:

- HTML: Creates the structure of a webpage.
- CSS: Adds design and styling.
- JavaScript: Adds interactivity and functionality.

3. The webpage running in the browser using Live Server.
