Assignment 2.1 — Creating Your First HTML Webpage

Q1. How do you create an "index.html" file?

Answer: Open Visual Studio Code, create a new file, name it "index.html", and save it in your project folder.

Q2. Which basic elements are used to create an HTML webpage?

Answer: The basic HTML elements are "<!DOCTYPE html>", "<html>", "<head>", and "<body>". They define the document type, HTML document, page information, and visible content.

Q3. How do you set the page title to "My First Webpage"?

Answer: Use the "<title>" element inside the "<head>" section.

<title>My First Webpage</title>

Q4. How do you add a main heading and at least three subheadings?

Answer: Use the "<h1>" element for the main heading and "<h2>" elements for subheadings.

<h1>Welcome to My First Webpage</h1>

<h2>About Me</h2>
<h2>My Education</h2>
<h2>My Hobbies</h2>

Q5. How do you add HTML comments and maintain proper indentation?

Answer: HTML comments are written using "<!-- comment -->". Proper indentation means adding spaces to organize the code and make it easier to read.

Example:

<!-- This is the main heading -->
<h1>Welcome to My First Webpage</h1>

Q6. How do you verify the webpage in a browser?

Answer: Save the "index.html" file, right-click it in Visual Studio Code, and select Open with Live Server. The webpage will open in the browser.

Q7. Write the complete HTML code for the webpage.

Answer:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Webpage</title>
</head>
<body>
    <!-- Main heading -->
    <h1>Welcome to My First Webpage</h1>

    <!-- About Me section -->
    <h2>About Me</h2>
    <p>Hello! I am a student learning HTML and web development.</p>

    <!-- Education section -->
    <h2>My Education</h2>
    <p>I am pursuing my Bachelor's degree in Business Administration.</p>

    <!-- Hobbies section -->
    <h2>My Hobbies</h2>
    <p>I enjoy reading books, learning new skills, and exploring technology.</p>
</body>
</html>
