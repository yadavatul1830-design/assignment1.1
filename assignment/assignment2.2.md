Q1. Write your name in the main heading.

Answer: I used the "<h1>" tag to display my name, Radhika Singh, as the main heading of the webpage.

Q2. Write an introduction paragraph in the About Me section.

Answer: I created an About Me section using the "<p>" tag to introduce myself as a BBA student at Invertis University.

Q3. Create sections for education, skills, and hobbies.

Answer: I created separate sections for Education, Skills, and Hobbies using HTML headings and paragraphs.

Q4. Use h1 to h6 headings in appropriate places.

Answer: I used heading tags from "<h1>" to "<h6>" to organize the webpage content according to importance.

Q5. Use p for paragraphs, br for line breaks, and hr for separators.

Answer: I used "<p>" to write paragraphs, "<br>" to add line breaks, and "<hr>" to separate different sections.

Q6. Use strong, em, and i for important text.

Answer: I used "<strong>" to highlight important text, "<em>" to emphasize words, and "<i>" to display text in italics.

Q7. Organize related content using div and inline content using span.

Answer: I used "<div>" to group related content into sections and "<span>" to highlight specific words within a line.
